About This Project

This website was created as an academic accessibility project using semantic HTML and CSS. The project follows WCAG-friendly structure and includes keyboard accessibility features.

The site demonstrates the use of CSS Grid, Flexbox, hover effects, box model styling, responsive layout, accessible navigation, and properly structured headings.
